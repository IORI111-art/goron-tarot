ごろんタロット ～祈緒里の町～ 試作2号

中身:
- index.html : アプリ本体
- icon.png : 黒猫アイコン
- manifest.webmanifest : Androidホーム画面/PWA設定
- sw.js : オフライン用

重要:
このPWAをAndroidのホーム画面へ「アプリ」として追加するには、HTTPSで公開されたURLから開く必要があります。
content:// や file:// で直接開いた場合、Chromeの「ホーム画面に追加／アプリをインストール」が出ないことがあります。

公開後:
1. Android Chromeで公開URLを開く
2. Chromeメニューから「アプリをインストール」または「ホーム画面に追加」
3. ホーム画面に黒猫アイコンが表示されます
